# Part 3 · Discovery (2:00–3:00)

**오늘은 우리가 말하기보다 듣는 시간입니다.** 끝날 때 PoC 범위 1개와 "맞았다"의 기준에 합의하는 것이 목표입니다.

| 시간 | 여쭤볼 것 |
|---|---|
| 2:00–2:15 | **최근 인시던트 1–2건:** 누가 언제 처음 알았나요? 진짜 장애라고 확신한 시점은? 몇 팀을 거쳤나요? |
| 2:15–2:30 | **가진 데이터:** 비즈니스 메트릭, 이벤트 캘린더, 서비스 owner 정보, 기존 에이전트는 어디에 어떤 형태로 있나요? |
| 2:30–2:45 | **신뢰의 기준 (핵심):** 놓친 장애와 오경보 중 무엇이 더 치명적인가요? 오라우팅은 몇 %까지 허용되나요? 사람 검증은 언제 뺄 수 있나요? |
| 2:45–3:00 | **PoC 하나 고르기:** 오늘 본 것 중 가장 먼저 효과를 볼 곳은? 정답셋(과거 포스트모템)은 누가 준비하나요? |

!!! tip "진행 원칙"
    - 기능 설명으로 흐르지 않게 합니다. 답이 막히면 오늘 실습 장면(판별, 근거 패키지, INCONCLUSIVE)을 예로 들어 다시 묻습니다.
    - 정확도 수치는 약속하지 않고 **측정 방법**만 약속합니다. 모르는 것은 "확인 후 공유"로 돌립니다.

기록용 양식은 [템플릿](templates.md)에 있습니다.
